# Неизвестный художник: Адольф Гитлер

Историко-музейный веб-проект о художественных работах, приписываемых Адольфу Гитлеру. Проект не является музеем личности, политическим манифестом или попыткой эстетизировать нацистскую идеологию. Его задача — показать объекты в контексте истории, спорной атрибуции, происхождения и публичного обращения с ними.

## Что внутри

Сайт содержит избранный зал с работами из Wikimedia Commons, три документальные книжные пластины, интерактивную карту пяти исторических точек Вены и полный архив из 198 загруженных материалов. В каталоге 97 страниц книги и 101 изображение из набора; архив поддерживает поиск и фильтры. Для объектов из Wikimedia Commons указаны страницы файлов и лицензии, а для пользовательских материалов сохранены исходные имена и осторожная отметка о необходимости сверки атрибуции.

На странице также есть краткая хронология художественного периода, раздел о проблемах подлинности и список источников. Карта использует Leaflet и тайлы OpenStreetMap; каталог загружает миниатюры лениво через статический JSON-манифест. Сайт сделан без backend-зависимостей и запускается как обычная статическая страница.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер из корня проекта. Например:

```bash
python3 -m http.server 8080
```

Затем перейдите на `http://localhost:8080`.

## Источники и атрибуция

Главный библиографический ориентир — *Adolf Hitler, the unknown artist* (B.F. Price, Houston, 1984), перевод немецкого каталога *Adolf Hitler als Maler und Zeichner*. Запись книги доступна на [Internet Archive](https://archive.org/details/adolfhitlerunkno0000hitl); полный текст имеет ограниченный доступ. Сайт показывает только отдельно загруженные пользователем страницы как документальные материалы и не является открытой копией всей книги. Фактический контекст дополнительно сопоставлен со статьёй Википедии, материалами HISTORY, BBC News / Reuters и ABC News. Изображения загружены с Wikimedia Commons. Перед повторным использованием проверьте условия конкретной юрисдикции и сохраните ссылку на карточку файла.

## Нейтральная рамка

Адольф Гитлер был лидером нацистской Германии и ответственен за преступления режима, включая Холокост. Его ранние художественные работы не должны рассматриваться отдельно от этой истории. Сайт избегает хвалебных характеристик и не использует нацистскую символику в оформлении.
