# Неизвестный художник: Адольф Гитлер

Историко-музейный веб-проект о художественных работах, приписываемых Адольфу Гитлеру. Проект не является музеем личности, политическим манифестом или попыткой эстетизировать нацистскую идеологию. Его задача — показать объекты в контексте истории, спорной атрибуции, происхождения и публичного обращения с ними.

## Что внутри

Сайт содержит две карточки работ из Wikimedia Commons: автопортрет 1926 года и акварель «Внутренний двор старой резиденции в Мюнхене» 1914 года. Для каждой карточки указана ссылка на страницу файла с описанием, источником и сведениями о лицензии. В текстах намеренно используется осторожная формулировка «приписывается» там, где речь идёт не о бесспорно подтверждённой атрибуции.

На странице также есть краткая хронология художественного периода, раздел о проблемах подлинности и список источников. Сайт сделан без backend-зависимостей и запускается как обычная статическая страница.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер из корня проекта. Например:

```bash
python3 -m http.server 8080
```

Затем перейдите на `http://localhost:8080`.

## Источники и атрибуция

Фактический контекст подготовлен по статье Википедии, материалам HISTORY, BBC News / Reuters и ABC News. Изображения загружены с Wikimedia Commons. Перед повторным использованием проверьте условия конкретной юрисдикции и сохраните ссылку на карточку файла.

## Нейтральная рамка

Адольф Гитлер был лидером нацистской Германии и ответственен за преступления режима, включая Холокост. Его ранние художественные работы не должны рассматриваться отдельно от этой истории. Сайт избегает хвалебных характеристик и не использует нацистскую символику в оформлении.
